# Changelog

## 0.1.0

- Added a self-hosted Docker Compose stack with PostgreSQL migrations, Redis, Celery, FastAPI, and a Next.js dashboard.
- Added isolated projects, test credentials, rotation, revocation, and audit history.
- Added core Razorpay-compatible orders, payment retrieval and capture, refund operations, and deterministic payment controls.
- Added immutable signed webhook events, bounded asynchronous retries, crash recovery, and payment and webhook chaos cases.
- Added YAML and JSON reliability suites, protected application-side assertions, and JSON, HTML, and JUnit exports.
- Added the installable CLI and working FastAPI and Express examples.
- Added a disposable CI workflow, dependency and secret scans, restart tests, and a recorded local load run.
- Licensed original LocalPay code under Apache 2.0.
