# LocalPay 0.1.0 release notes

The first release lets developers test a documented subset of Razorpay flows against a local simulator, reproduce payment and webhook failures, and run observable integration assertions in a dashboard or automated pipeline.

It includes a Docker Compose stack, an installable CLI, FastAPI and Express examples, report exports, and a disposable CI workflow. Start with the [quick start](quick-start.md) and check the [compatibility matrix](compatibility.md) before changing a development integration.

The release uses the Apache License 2.0 for original LocalPay code. See the [verification report](verification.md) for measured coverage, security scope, and remaining limitations.
